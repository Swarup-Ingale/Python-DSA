# Operators

- Arithmetic - + - * / % // **
- Comparrision: < > <= >= == !=
- Assignment : += -= *= /= //= **=
- Logical : and or not
- Bitwise: & | ~ !
- Identity: is is not
- Membership: in in not
- Walrus: := 
- Ternary: if else elif

50 - 110010
